# Расписание 10 МА-13

Веб-приложение с расписанием + пуш-уведомления на айфон.

- `schedule.json` — расписание и настройки. Главное поле — `skip`: впиши туда предметы, которые можно проспать, например `"skip": ["Українська мова", "Історія України"]`.
- `morningHour` / `eveningHour` — во сколько приходят утренняя сводка и вечернее «во сколько ставить будильник» (по Киеву).
- Пуши шлёт GitHub Actions (`.github/workflows/push.yml`), ключ хранится в секрете `PUSH_CONFIG`.
